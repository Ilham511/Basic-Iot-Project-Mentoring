# Project Documentation

## Activity Overview

This project-based learning activity was conducted for 40 new students of Automotive Engineering.

The participants were divided into four groups. Each group developed one IoT-based prototype with guidance from three student facilitators.

## Activity Stages

The activity consisted of:

1. Introduction to basic IoT concepts
2. Project assignment
3. Project development
4. Project completion
5. Prototype presentation and exhibition

## Developed Prototypes

The four groups developed:

- Vehicle Parking Sensor
- GPS Vehicle Monitoring
- Room Temperature Monitoring
- AC Electrical Energy Monitoring

## Activity Outcome

All four groups successfully completed their assigned prototype projects and presented their projects during the campus exhibition.

The activity documentation focuses on the implementation process, project outputs, and learning activities. It does not measure learning effectiveness or competency improvement using pre-test, post-test, questionnaires, or standardized assessment instruments.
