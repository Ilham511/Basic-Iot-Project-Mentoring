# Learning Materials

This folder contains supporting materials used during the basic IoT project mentoring activity.

## Topics

The learning activity covered basic topics related to:

- Introduction to ESP32
- Basic IoT concepts
- Sensor and module integration
- Basic programming
- Project-based learning
- Prototype development

## Project Modules

The mentoring activity covered four project modules:

1. Vehicle Parking Sensor
2. GPS Vehicle Monitoring
3. Room Temperature Monitoring
4. AC Electrical Energy Monitoring

The materials were used to support hands-on project development by the participants.
