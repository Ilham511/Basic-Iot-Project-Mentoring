# AC Electrical Energy Monitoring

## Project Overview

This project is an ESP32-based AC electrical energy monitoring prototype developed as part of a group-based IoT project learning activity.

The system uses a PZEM-004T module to monitor electrical parameters from an AC load. The ESP32 processes the measurement data and provides monitoring information.

## Hardware

- ESP32
- PZEM-004T
- Relay
- Electrical socket
- Breadboard
- Jumper wires

## Monitored Parameters

The system is designed to monitor:

- Voltage
- Current
- Power
- Energy
- Frequency
- Power factor

## System Concept

The PZEM-004T measures electrical parameters from the connected AC load. The ESP32 receives and processes the measurement data for monitoring purposes.

## Project Context

This prototype was developed by a group of new Automotive Engineering students under the guidance of student facilitators.

The code in this repository is a reimplemented version based on the project specifications and activity documentation. It is not the original source code used during the activity.

## Safety

AC electrical systems involve hazardous voltages. Testing and wiring should only be performed using appropriate safety procedures, protection, and supervision.
