# GPS Vehicle Monitoring

## Project Overview

This project is an ESP32-based GPS vehicle monitoring prototype developed as part of a group-based IoT project learning activity.

The system uses a GPS module to obtain vehicle position information. The ESP32 processes the GPS data and can display location-related information through the monitoring interface.

## Hardware

- ESP32
- GPS module
- Breadboard
- Jumper wires

## System Concept

The GPS module receives positioning data from satellites. The ESP32 reads and processes the GPS data to obtain information such as latitude, longitude, and vehicle speed.

## Project Context

This prototype was developed by a group of new Automotive Engineering students under the guidance of student facilitators.

The code in this repository is a reimplemented version based on the project specifications and activity documentation. It is not the original source code used during the activity.
