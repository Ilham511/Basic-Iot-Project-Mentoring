# Room Temperature Monitoring

## Project Overview

This project is an ESP32-based room temperature monitoring prototype developed as part of a group-based IoT project learning activity.

The system uses a DHT11 sensor to monitor room temperature and humidity. The measured data is processed by the ESP32 and displayed on an LCD.

## Hardware

- ESP32
- DHT11 temperature and humidity sensor
- LCD I2C
- Breadboard
- Jumper wires

## System Concept

The DHT11 sensor measures room temperature and humidity. The ESP32 reads the sensor data and displays the measurement results on the LCD.

## Project Context

This prototype was developed by a group of new Automotive Engineering students under the guidance of student facilitators.

The code in this repository is a reimplemented version based on the project specifications and activity documentation. It is not the original source code used during the activity.
